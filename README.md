# I Always Win

Щоденна система перемог: звички, плани на день, записник, фінанси, цілі й галерея мрії.
Встановлюється як застосунок (PWA) на телефон і компʼютер, працює без інтернету.
Дані зберігаються на пристрої (localStorage) і, якщо увімкнути «Налаштування → Синхронізація між пристроями», у приватному сховищі Vercel Blob.
Пристрої з однаковим кодом синхронізації обмінюються даними через `api/sync.js` (стан) і `api/img.js` (фото мрій); зміни зливаються потрійним злиттям, тож записи з обох пристроїв не губляться.

Статичний сайт без збірки: `index.html`, `sw.js`, `manifest.webmanifest`, `icons/`, `vendor/`, плюс дві функції в `api/` (потрібна змінна `BLOB_READ_WRITE_TOKEN`).
Після змін збільшіть `VERSION` у `sw.js`, щоб встановлені копії отримали оновлення.
